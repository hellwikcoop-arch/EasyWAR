# Проксі Комбата: контрольний рубіж

Сервіс призначено для синтетичної перевірки й локальної підготовки. `start.mjs` слухає
лише `127.0.0.1`; новий журнал витрат створюється з `enabled: false`. Застосунок
EasyWAR поки не викликає цей проксі: немає погоджених JE адреси сервісу, схеми
автентифікації користувачів і підтвердження залишку промокредитів. Ключ Anthropic
зберігається лише в змінній середовища сервера, не в пакеті застосунку.

Обов'язкові змінні сервера: `ANTHROPIC_API_KEY`, `KOMBAT_ACCESS_TOKEN`,
`KOMBAT_ADMIN_TOKEN`, `KOMBAT_LEDGER_PATH`, `KOMBAT_BUDGET_CENTS` (1–10000,
у центах USD). Не розміщуйте токени у клієнтському JavaScript або публічній збірці.
`KOMBAT_PORT` необов'язковий. Маршрути: `POST /v1/chat` з Bearer access-токеном,
`GET /admin/status` і `POST /admin/disable` з окремим Bearer admin-токеном.
Тіло чату містить тільки `{ "messages": [{ "role": "user", "content": "..." }] }`;
файли, таблиці, довільний system prompt та інші поля відхиляються.

Кожен запит резервує консервативну суму на диску *до* виклику Anthropic. Резерв
ніколи не повертається після помилки, скасування чи обриву потоку. Додатково
зберігається оцінка фактичного використання за `usage`, але саме сумарний резерв
обмежує запити. Файл журналу має бути на локальному надійному диску; один процес
блокує його через `.lock`. Після аварії застарілий lock знімає оператор лише після
перевірки, що процес справді завершився. Якщо запис журналу неможливий, запит
не йде до Anthropic. Обмеження — два одночасні запити.

Цей програмний ліміт **не підтверджує** чинність $100 промокредитів і не зупиняє
платне списання в обліковому записі Anthropic, якщо кредитів немає або їх умови
змінилися. Перед активацією JE має перевірити баланс/строк кредитів та виставити
незалежний ліміт витрат у провайдера. Потрібні окремі рішення JE щодо адреси,
автентифікації, розкриття передачі тексту користувачеві й правила активації.
Публічний доступ не ввімкнений цим PR.
