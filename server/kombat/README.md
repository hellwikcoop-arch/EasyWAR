# Комбат: контрольоване розгортання API-проксі

Проксі приймає лише короткі текстові репліки, передає їх Anthropic Messages API і
повертає SSE. Він не має доступу до локальних файлів, SQLite, Signal чи таблиць
EasyWAR. У застосунку вкладка «Онлайн» вимагає явної HTTPS-адреси та персонального
токена. До натискання «Надіслати запитання» мережевого запиту немає. Локальна довідка
й локальна модель залишаються окремим офлайн-режимом.

## Передумови та ключі

Сервер має працювати на захищеному хості з локальним надійним диском. Новий журнал
витрат створюється з `enabled: false`; за замовчуванням також заборонено серверний
дозвіл на ввімкнення. Потрібні змінні середовища сервера:

| Змінна | Призначення |
| --- | --- |
| `ANTHROPIC_API_KEY` | Ключ лише на сервері; ніколи не передавати в застосунок |
| `KOMBAT_ADMIN_TOKEN` | Окремий випадковий 64-символьний hex-токен оператора |
| `KOMBAT_LEDGER_PATH` | Абсолютний шлях до журналу, наприклад `/var/lib/kombat/ledger.json` |
| `KOMBAT_BUDGET_CENTS` | Верхня межа резерву в центах USD, 1–10000; для одного тесту задайте малий ліміт |
| `KOMBAT_ALLOWED_ORIGINS` | Точні Origin тестових збірок через кому, без `*` |
| `KOMBAT_PORT` | Необов'язково, за замовчуванням 8765 |
| `KOMBAT_ENABLE_AFTER_JE_APPROVAL` | Лише після окремого дозволу JE на платний реальний тест: `1`; за замовчуванням вимкнено |

Згенеруйте admin-токен поза Git і не передавайте його в аргументах командного рядка.
Запустіть `node server/kombat/start.mjs` під окремим системним користувачем із
мінімальними правами. Сервіс слухає тільки `127.0.0.1`; адміністрування доступне
лише з цього хоста. Не записуйте ключі або токени в логи, конфігурацію frontend,
репозиторій чи резервні копії без шифрування.

## HTTPS і доступ застосунку

Перед локальним портом потрібен HTTPS reverse proxy із чинним сертифікатом та
мережевим обмеженням для тестової групи. Назовні пропускайте **лише** `/v1/chat`
(POST і CORS preflight OPTIONS); `/admin/*` лишається на localhost. Наприклад,
правило Caddy для тестового домену, доступного тільки через VPN:

```caddyfile
kombat-test.example.org {
  handle /v1/chat {
    reverse_proxy 127.0.0.1:8765
  }
  handle {
    respond 404
  }
}
```

Додайте до `KOMBAT_ALLOWED_ORIGINS` фактичні Origin тестових webview. Для типових
Tauri 2 це `tauri://localhost` на macOS та `http://tauri.localhost` на Windows;
перевірте значення в конкретній збірці. Для локального браузерного тесту додайте
лише його точний Origin. Довільні Origin сервер відхиляє. CSP і Tauri capabilities
цей PR не змінює.

## Видача й відкликання

Після запуску оператор із `KOMBAT_ADMIN_TOKEN` у власному середовищі виконує:

```text
node server/kombat/admin.mjs status
node server/kombat/admin.mjs issue tester-01
node server/kombat/admin.mjs revoke <id-з-відповіді-issue>
node server/kombat/admin.mjs disable
```

`issue` показує новий випадковий токен **один раз**. Передайте його одному
тестувальнику захищеним каналом; не використовуйте спільний токен. Журнал зберігає
лише SHA-256 хеш токена, псевдонім, ID, стан відкликання й лічильники витрат.
Відкликання одразу відхиляє нові запити та скасовує активні запити цього токена.
У EasyWAR тестувальник вводить HTTPS-адресу й токен у вкладці «Онлайн». Токен
живе лише в пам'яті поточного входу в профіль і стирається з доступного стану
після виходу/закриття застосунку; у localStorage, SQLite й файл він не записується.
Це навмисно не забезпечує автоматичного повторного входу. Через чинний `CSP: null`
для публічного запуску потрібен окремий перегляд безпеки webview.

## Дозвіл на реальний тест і облік

До окремого дозволу JE лишіть `KOMBAT_ENABLE_AFTER_JE_APPROVAL` не встановленим:
навіть якщо старий журнал містить `enabled: true`, запити до Anthropic не йдуть.
Після письмового дозволу на конкретний реальний тест оператор перевіряє баланс і
строк промокредитів Anthropic, виставляє незалежний провайдерський ліміт,
задає малий `KOMBAT_BUDGET_CENTS`, перезапускає сервіс із
`KOMBAT_ENABLE_AFTER_JE_APPROVAL=1`, тоді виконує `node server/kombat/admin.mjs enable`.
Команда `disable` зупиняє акцію на сервері й скасовує активні запити.

Перед кожним тестом і після нього перевірте `admin.mjs status`: `committedCents`
є сумою **незворотних резервів**, `actualCents` — оцінкою за API `usage`, а
`tokens[].reservedCents`/`actualCents` дають розріз по тестувальниках. Зіставте
це з консоллю Anthropic; локальний підрахунок не є рахунком провайдера. Резерв
фіксується на диску до виклику API й не повертається після обриву або скасування.
Одночасно допускаються щонайбільше два запити. Застарілий `.lock` після аварії
знімайте лише після підтвердження, що процес завершився. Програмний ліміт сам по
собі не гарантує відсутності платних списань, якщо промокредити недійсні.

**Цей PR не запускає реальний тест, не вмикає акцію і не відкриває публічний доступ.**
