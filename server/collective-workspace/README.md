# Сервер колективного файлового середовища

Окремий Cloudflare Worker. EasyWAR **сам нічого не розгортає** і не містить ключів цього сервера.
Поки в екрані «Колективи» не вказано адресу, застосунок лишається локальним.

## Що робить сервер

- Один Durable Object на колектив (`CollectiveRoom`) зберігає учасників, файли й журнал.
- Окремий Durable Object (`CodeDirectory`) зберігає лише 6-значні коди й лічильник невдалих спроб.
- Код запрошення: 6 цифр, 24 години, одне використання, не більше 8 невдалих спроб з однієї IP-адреси за 15 хвилин.
- Код і жетон учасника не входять у знімок, який бачать інші учасники.
- Ролі перевіряє сервер. Керівників у колективі не може стати нуль.

Матриця:

| Дія | Керівник | Молодший керівник | Користувач |
|---|---|---|---|
| Запросити (роль «Керівник», «Молодший керівник» або «Користувач») | так | лише «Користувач» | ні |
| Призначити або змінити роль | так | ні | ні |
| Вилучити іншого учасника | так, якщо лишається хоча б один Керівник | ні | ні |
| Створити, оновити, перейменувати, видалити файл | так | так | так |

Журнал дописується лише на сервері (хто, що, коли). Повний текст коду в журнал не пишеться.
Якщо файл зберегли з застарілої версії, сервер відповідає конфліктом і віддає актуальний вміст.

Обмін — коротке опитування (клієнт питає знімок приблизно кожні 2 секунди). Вікно застосунку само на сервер не ходить: з’єднання робить оболонка і лише на адресу, яку ввели.

## Розгортання

Потрібен обліковий запис Cloudflare. З каталогу цього сервера:

```bash
npx wrangler@4 login
npx wrangler@4 deploy
```

Wrangler надрукує адресу на кшталт `https://easywar-collective-workspace.<account>.workers.dev`.
Її вписують у «Колективи» → «Адреса сервера обміну». Секретів задавати не треба: жетони видає сам сервер під час створення й вступу.

Свій домен (необов’язково): у панелі Cloudflare прив’яжіть його до цього Worker і впишіть уже його `https://…` адресу. Шлях має бути порожній: застосунок сам додає `/v1/…`.

Локальна перевірка без хмари: `npx wrangler@4 dev` піднімає `http://127.0.0.1:8787`. Цю loopback-адресу EasyWAR приймає лише для перевірки. Учасники на інших комп’ютерах її не бачать — їм потрібна публічна `https://` адреса.

Не викладайте в репозиторій `wrangler.toml` з `account_id`, файли `.wrangler/` і жодні токени.
