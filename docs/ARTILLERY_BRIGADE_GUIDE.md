# Артилерія: коротка інструкція для бригад

Модуль «Артилерія» (easyWAR, beta) допомагає внести витрату й залишок боєприпасів у спільну таблицю `.xlsx` і побачити зведення. Файл лишається тим самим: оновлюються тільки клітинки вашого підрозділу, формули та дані інших бригад не змінюються.

## Перед початком

1. Візьміть **свіжу** копію спільної таблиці з Nextcloud (дочекайтеся синхронізації або завантажте файл).
2. Запустіть easyWAR і оберіть блок **«Артилерія»**.
3. Натисніть **«Відкрити таблицю…»** і виберіть файл (або перетягніть його у вікно). Якщо ви вже працювали з ним, є кнопка **«Продовжити»**.

## Внесення даних

1. Вкладка **«Внесення»** → оберіть **свій підрозділ** (із емблемою).
2. Перевірте **дату й звіт**: **17:00** чи **24:00**. Застосунок пропонує їх за поточним часом.
3. Поля вже містять поточні значення з таблиці. Змініть **витрату** і **залишок** по потрібних типах; чого не чіпали, те лишається як було. Числа цілі, без дробів. Якщо стерти значення, клітинку буде очищено.
4. За потреби внесіть **ВгЗ**, **КББ**, **заряди** і **втрати противника** (вони тут же, нижче).
5. Змінені поля підсвічуються. Натисніть **«Зберегти»** (панель внизу).

## Збереження: дві можливості

- Мітка **«прямий запис»** вгорі: зміни пишуться просто у файл. Після цього файл лишається на місці, і Nextcloud сам його розвезе.
- Мітка **«через завантаження»**: застосунок віддасть оновлений файл на завантаження. **Замініть ним спільний файл у Nextcloud** (ім'я не змінюйте).

Якщо поки ви вводили дані, файл змінила інша бригада, ваші дані буде дописано до свіжої версії файлу, чужі зміни не пропадуть.

## Перед вигружанням у Nextcloud

1. Відкрийте вкладку **«Перевірка»**: там зауваження до таблиці (дублі підрозділів, від'ємні чи дробові числа, порожні підсумки). Виправте те, що стосується вашого підрозділу.
2. На **«Зведенні»** і **«Боєприпасах»** перегляньте, чи збігається витрата й залишок з вашими даними. На матриці ▼ означає малий залишок, ✕ — вичерпаний.
3. Вигрузіть файл у Nextcloud **одразу** після збереження. Не тримайте локальну копію днями: інші бригади вносять у той самий файл.
4. Не вносьте дані одночасно з іншою бригадою в один файл, якщо цього можна уникнути.

## Корисно знати

- Формули в таблиці перерахуються, коли її відкриють в Excel чи в Nextcloud. Сам застосунок рахує підсумки напряму з клітинок.
- Вкладка **«Довідник»**: стаття про кожен тип боєприпасів, 3D-модель і підсумок по вашій таблиці.
- Є прихований аркуш **«EasyWAR_Артилерія»**: у ньому журнал внесень (час, підрозділ, кількість змін). Його не видаляйте.
- Якщо колонка вашого підрозділу в таблиці без назви, застосунок попросить вказати назву під час внесення.
