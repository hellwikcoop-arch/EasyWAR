# Докази T-0018: CSP головного вікна (JE-21 варіант а), 29.10.2026

Статус: **перевірено в браузері (Linux, Chromium через скіл `run-easywar`) з емульованим заголовком
Tauri; у реальному webview Tauri (Windows/macOS, WebKitGTK) — не перевірено.** Лише синтетичні дані
(`fixtures.py`); ключ Planet не вводився; зовнішні плитки в контейнері не завантажувалися (мережа),
тому дозволені хости `img-src` перевірено лише як текст політики.

## Як емульовано Tauri

`dist/` після `npm run build` віддавав статичний сервер, що до кожної HTML-сторінки додавав
заголовок `Content-Security-Policy` з рядком `app.security.csp` із `tauri.conf.json`, і — як робить
`tauri-codegen` — дописував до `script-src` `'sha256-…'` хеші inline-скриптів сторінки та `'nonce-…'`
(через це браузер ігнорує `'unsafe-inline'` для скриптів); `style-src` не змінювався
(`dangerousDisableAssetCspModification: ["style-src"]`). Порушення CSP у Chromium — це помилки
консолі «violates the following Content Security Policy directive», які збирає `driver.mjs errors`.

## Сценарії

| Сценарій | Результат |
|---|---|
| Лаунчер `index.html` (заставка, картки родів військ) | без порушень (лише favicon 404) |
| Лаунчер → ПС (iframe) → таблиця 240 рядків → картка GBU-39 з 3D | без порушень; 3D відмальовано ([знімок](2026-10-29-gbu39-3d.png)) |
| `rocket.html` → таблиця → дашборд (KPI) | без порушень |
| `air.html` → таблиця → дашборд; `map.html` (3D-рельєф, worker з Blob, .glb) | без порушень |
| Лаунчер → «Робоче середовище» (iframe `workspace/index.html`) | без порушень |
| Офіс: EasyGreen (WASM) ([знімок](2026-10-29-easygreen.png)), EasyDoc (WASM, [знімок](2026-10-29-easydoc.png)), EasySlide (WASM) | без порушень; редактори відмальовано |
| easyWIKI: хаб `guides/index.html`, «Авіація» (three.js, .glb з текстурами) | **перша версія політики ламала текстури** (`connect-src` без `blob:` — GLTFLoader читає текстури через `fetch(blob:)`); після додавання `blob: data:` до `connect-src` — без порушень |

Знахідки, що змінили таблицю ADR §5: `frame-src 'self'` (модулі, Офіс і довідники — iframe власних
сторінок), `font-src 'self' data:` (шрифти в `air.html`/`rocket.html`/`index.html`), `media-src 'self'
blob:` (заставка через `URL.createObjectURL`), `connect-src … blob: data:` (текстури .glb).

## Не перевірено

- Windows/macOS і WebKitGTK: поведінка `'wasm-unsafe-eval'`, `ipc:`/`http://ipc.localhost`, хешів
  Tauri — потрібен прогін власника або CI на тегах; у разі помилок «Refused to …» у консолі
  webview — доповідь JE, CSP відкочується одним рядком.
- Live-плитки OSM/ArcGIS/Planet, dimap.live у iframe (мережа контейнера).
- Вікно редактора Офісу як окреме вікно Tauri (`workspace_open_editor`): CSP головного вікна
  застосовується до всіх webview застосунку — перевірити на десктопі.

## Залишкові ризики (P2-1 частково)

`'unsafe-inline'` для скриптів — лише до переходу legacy HTML на хеші (у webview Tauri не діє через
додані хеші), для стилів — потрібен; ключ Planet у URL плиток (P2-2); команди Tauri доступні
будь-якому скрипту головного вікна (фасад для iframe — окремий пункт).
