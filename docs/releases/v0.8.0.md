Окремі таблиці для Повітряних Сил і Ракетних військ в одному профілі: кожна відкривається у своєму модулі й записується у свій файл. Раніше прив'язана таблиця стає таблицею Повітряних Сил.

У профілі можна створити порожню базову таблицю: ПС, ПС рівня ПВК (ТАБЛ 2-3; дашборд під неї ще в розробці) або РВіА. Наявний файл не перезаписується.

На стартовому екрані з'явився блок «Армійська Авіація» з позначкою «У розробці».
