# EasyWAR 0.9.0

У модулі «Повітряні Сили» з'явився окремий дашборд для таблиці ПС рівня
ПВК (ТАБЛ 2-3). Він читає аркуші «АА», «ПС» і «Об'єкти», показує всі 57
показників із заголовків базової таблиці, не приховує нульові значення й
автоматично додає нові невідомі стовпці до групи «Інші показники».

Додано «Зведення ПВК», окремі сторінки трьох аркушів, вибір періоду,
зведену таблицю з CSV-вивантаженням і перевірку даних. «Витрата» рахується
окремо від уражених об'єктів, а відсоток уражених безпечно обробляє нульовий
знаменник.

Таблиця ПВК відкривається лише для читання. Внесення доповідей і
Signal-перегляд для неї вимкнені з поясненням; звичайна таблиця ПС з аркушем
«Зведена» та модуль РВіА продовжують працювати без зміни формату.

Перевірки релізу: `npm run test:unit`, `npm run build`, `cargo test` у
`src-tauri`.
