# J3 dashboard flow prototype

Автономний інтерактивний прототип оновленого UX для трьох екранів:

1. створення модуля та зіставлення XLSX;
2. перевірка проблемних значень перед імпортом;
3. робоча таблиця журналу на 35 колонок.

Прототип використовує лише синтетичні дані, не викликає Tauri-команди, не
відкриває файли користувача та нічого не записує до SQLite.

## Запуск

З кореня репозиторію:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

Після цього відкрити:

```text
http://127.0.0.1:4174/docs/design/j3-dashboard-flow-prototype/
```

У верхній панелі можна перемикати три екрани. На екрані таблиці працюють:

- пошук за типом або номером ПС;
- фільтри груп колонок;
- компактна і звичайна щільність;
- закріплені перші три колонки та колонка дії;
- панель додавання/редагування рядка.
