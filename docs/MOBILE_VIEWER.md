# Перегляд на телефоні (PWA)

`viewer.html` — окрема сторінка для телефона (Android і iPhone), без Tauri. Вона
показує лише два дашборди: **ПВК** (`air.html?command=pvk`) і **УДШВ**
(`rocket.html?command=dshv`), тільки для читання. Ті самі модулі, що й у
десктопі, відкриваються в `<iframe>` командним режимом; окремого мобільного
коду немає.

## Що працює

- Таблицю `.xlsx` користувач обирає на телефоні («Відкрити таблицю…»). Файл
  читається в браузері й нікуди не надсилається; на iOS і Android працює
  запасний шлях через `<input type="file">`.
- Після першого відкриття сторінки з інтернету сервіс-воркер (`sw.js`) кешує
  весь застосунок (близько 17 МБ). Далі він запускається без мережі.
- Іконка на екрані: «Додати на головний екран» (`manifest.webmanifest`).
- Запис у файл, база даних SQLite, внесення доповідей, довідник і 3D-моделі
  (`*.glb`) на телефоні недоступні.

## Як збирається

`npm run build` додає до `dist/` сторінку `viewer.html`, маніфест, іконки й
`sw.js`. Файл `sw.js` створює плагін у `vite.config.js` (`viewerServiceWorker`):
він бере список усіх файлів `dist/` (крім `*.glb` і `*.map`) і підставляє назву
кешу `easywar-viewer-<версія з package.json>`. Нова версія застосунку має новий
кеш, старий видаляється під час `activate`.

Сервіс-воркер реєструє тільки `viewer.html` і тільки поза `file:`. У Tauri його
немає, тож на десктоп ця функція не впливає.

## Розміщення

Для встановлення на телефон сторінку потрібно віддавати з **HTTPS** (сервіс-воркер
і «Додати на головний екран» на голому `http://` не працюють, крім `localhost`).
Підійде будь-який статичний хостинг: викласти вміст `dist/` (потрібні
`viewer.html`, `sw.js`, `manifest.webmanifest`, іконки, `assets/`, `air.html`,
`rocket.html`, `*.js`).

Врахуйте, що разом із сторінкою на хостинг потрапляє код модулів. Якщо
репозиторій приватний, а хостинг публічний (наприклад, GitHub Pages публічного
репозиторію), код стає доступним усім, хто знає адресу. Обирайте хостинг
свідомо.

## Перевірка вручну

```bash
npm run build
npx vite preview --port 4173 --strictPort
```

Відкрийте `http://localhost:4173/viewer.html` у вікні 390×844. Після першого
завантаження вимкніть мережу (DevTools → Network → Offline) і перезавантажте
сторінку: обидві плитки мають відкриватися. Автоматично перевіряється лише
статика (`tests/pwa-viewer.test.mjs`).
