Конфлікти `entry.js`, `fly-state.js` і посібника розв'язано вручну: редагування
поєднано з БП/СБП, календарними полями, однією датою статті 205 і новими reducers
хронометражу. Кнопки редагування лишилися в льотній книжці та хронометражі зміни.
Індекс довідки перегенеровано з об'єднаних джерел.

Додаткове виправлення інтеграції: мобільний host очікує `mounted.flush()` перед
unmount/видаленням ключа vault. За помилки запису нових змін документ залишається
відкритим для повторної спроби/експорту; помилка зайвого запису чистого документа
не заважає блокуванню. Під час очікування інтерфейс тимчасово inert.

  відсутній Cargo). Для тестів локального HTTP-сервера потрібен мережевий доступ
  sandbox; початкові відмови `listen EPERM` усунено повторним прогоном із ним.
- Цільовий EasyFLY + network boundary + актуальність індексу: 232/232.
- `npm run build`, `npm run build:easyfly-html`, `npm run build:easyfly-phone`: успішно.
  Автономний HTML: 0,69 МБ, синтаксис inline-модуля перевірено, зовнішніх src/href немає.
- `npm run audit:prod`: нових production advisory немає; два раніше прийняті
  advisory `image-size` лишаються за наявною політикою репозиторію.
- `node script/release_version.mjs`, `node script/assistant_index.mjs --check`,
  `git diff --check`: успішно.

  помилки сховища на чистому/зміненому документі, повторна спроба та reload.
  Запуск: `npm run dev:easyfly-phone -- --host 0.0.0.0 --port 4174 --strictPort`,
  потім `node tests/easyfly-integration.browser.mjs` (потрібні Playwright і Chromium;
  для зовнішньої інсталяції можна задати `PLAYWRIGHT_PATH`).

Залишкові ризики / межі перевірки:

- Rust/Cargo відсутні: `cargo test`, clippy, fmt і нативні збірки не перевірено локально.
  Windows/macOS EF-01…EF-12 з smoke-плану та справжній iPhone/Safari — NOT RUN.
- ОС може припинити процес до завершення асинхронного запису. Збій нового запису
  відкладає автоблокування, залишаючи UI/ключ відкритими для порятунку змін.
- `.easyfly` експорт — звичайний JSON, як у вихідних PR; Web Share та встановлення
  PWA на iOS не перевірено. Hosted PWA має manifest/іконки, але не service worker;
  холодне відкриття hosted-сторінки без мережі не гарантоване. Автономний HTML окремий.
- Вихідні PR не змінено; release, теги, production і `main` не змінено.
