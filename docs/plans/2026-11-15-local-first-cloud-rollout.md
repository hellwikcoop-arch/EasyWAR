# КРОК 1 — базовий захист EasyWAR і локальність даних

**Дата узгодження:** 15.11.2026. **Статус:** підготовка до приймання, без автоматичного злиття.
**Рішення JE:** робоча інформація обробляється на пристрої користувача; перевірені зовнішні API дозволені для службових функцій і публічних даних; обмін між учасниками — лише за явним дозволом, перевіреними правами та E2EE; сервер не отримує ключів або відкритого вмісту робочих пакетів.

## Межа цього кроку

КРОК 1 **не є** реалізацією хмарної синхронізації. На цьому кроці затверджуємо архітектурну межу та закриваємо два наявні очевидні мережеві канали: погодний API і встановлення локальної AI-моделі. Інші мережеві виклики залишаються в інвентарі для окремих перевірок. `WAN` і `Base44` не відкриваємо. Жодної передачі робочих даних, запуску платних API, деплою або створення зовнішніх облікових записів.

Базові правила — [ADR Local-first](../adr/local-first-connected-services.md) та [інвентар мережевих меж](../adr/network-and-secret-boundaries.md). Зберігаємо Tauri 2, Rust, SQLite, офлайн-роботу, ізоляцію профілів та чинні шифровані дані. Зміни виконуються вузькими PR, без переписування вже працюючого EasyWAR.

## Наступні етапи

**КРОК 2 — робочий EasyWAR + EasyFLY.** Основний пріоритет — повноцінне створення, редагування, збереження й відновлення записів; завершення робочих модулів та перевірки Windows/macOS. Нові мережеві функції не блокують цю роботу.

**КРОК 3 — зашифрований хмарний обмін.** Окремо перевіряємо Relay / `EnvelopeV1` / `send_gate.rs`, квитанції `put/fetch/ack`, відкликання членства, TTL, replay, fail-closed, метадані. Кандидат пілота — Cloudflare Workers + D1 + приватний R2, починаючи лише з синтетичних пакетів. WAN у продуктивному застосунку дозволяється **лише після окремого незалежного security review і рішення власника**.

**EasyFLY Pro** — майбутня функція, не входить до поточних трьох кроків.

## Звітність

Прогрес КРОКУ 1 рахується за чотирма рубежами по 25%; останні 25% не нараховуються до завершення сумісної перевірки й приймання. Відсоток завжди відноситься до цього звуженого КРОКУ 1, а не до готовності всієї системи захисту EasyWAR.
