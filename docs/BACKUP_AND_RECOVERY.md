# Резервна копія та відновлення

## Створення копії

1. У настільному EasyWAR натисніть «Резервна копія».
2. Прочитайте попередження й натисніть «Обрати місце й створити».
3. У системному вікні виберіть захищену папку та нове ім'я файлу `.sqlite3`.
4. Дочекайтеся повідомлення «Резервну копію створено й перевірено» та запишіть показаний шлях.

Застосунок створює узгоджений знімок локальної SQLite-бази й перевіряє його
цілісність перед збереженням. Поточну базу не змінює. Наявний файл не
перезаписує: у разі збігу імені виберіть інше.

Копія може містити всі локальні записи, налаштування й джерела. Зберігайте її
як чутливий файл. EasyWAR не шифрує копію й не завантажує її до хмари сам;
вибір синхронізованої папки означає окреме рішення користувача.

## Межі поточної версії

- Кнопка «Перевірити копію» читає вибраний файл без змін і звіряє цілісність,
  зв'язки, історію міграцій та обов'язкову структуру EasyWAR. Вона не
  відновлює дані. Копія з окремими файлами `-wal`, `-shm` або `-journal`
  відхиляється як неавтономна.
- Відновлення через інтерфейс ще не реалізоване. Не замінюйте файл відкритої
  бази вручну — це може пошкодити дані або обійти міграції.
- Перевірка цілісності підтверджує читабельність SQLite-знімка, але не є
  випробуванням повного відновлення застосунку.
- Перед випуском 1.0 потрібні контрольоване відновлення, перевірка версії
  схеми, сценарій перезапуску та синтетичний тест відновлення.
